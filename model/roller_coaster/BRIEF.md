**真实性铁律**（生成中心线时作为约束求解）：
- 速度全程按能量守恒 + 85% 滚阻/风阻效率推算，逐段校核；
- 回环顶点 g ≥ 1.2，峰谷 +3.5g 封顶，驼峰顶 -0.3~-0.5g；
- 所有平弯 banking 由横向 g ≤ 1.2 反解倾角，缓变过渡段 ≥ 6m（禁止倾角突跳）；
- 净空包络：心线两侧 ±1.6m、上方 2.2m 无结构侵入；低空段（<3.5m）下方加装饰保护网；
- 相邻段曲率连续（G1+），竖曲线最小半径按该段速度取 v²/(3g)。

## 3. 轨道结构

- **跑轨**：双钢管 Ø0.12m，沿心线法向架设（BMesh 圆管放样，断面 8 边，远小近大 LOD 不做，统一 8）；
- **桁架脊**：轨道下方三角/方管脊柱 + 之字斜撑，节距 1.2m（对应真实 steel box track）；
- **轨枕**：每 1.2m 一副，枕下接脊柱；提升段枕上加防逆棘齿，刹车段轨侧加暗红刹车鳍；
- **磷光描边**：脊柱侧沿全长贴 0.05m 磷光绿光带（emissive 材质），夜里勾出整条线形——本资产的招牌视觉；
- **道岔/转辙**：出站处装饰性转辙器 + 警示条纹。

## 4. 支撑结构

- 立柱：Ø0.5~0.9m 锥形钢管（随高度收细），暗夜紫近黑，节段法兰盘装饰；
- 柱距 8~12m，>15m 柱加双侧斜撑桁架；低空贴地段柱脚出混凝土基座+南瓜灯柱帽；
- 跨湖/跨路段用拱形组合柱（若 M0 定线经过湖区）。

## 5. 列车（单独 glb，运行时由 three.js 驱动）

- **头车**：南瓜战车造型——南瓜壳舱盖+骷髅前脸（磷光绿眼窝），无乘客席；
- **5 节客舱车**：每车 2 排×2 座，暗夜紫车体+南瓜橙包边，敞式座舱；

## 8. 导出与游戏接入（乘坐的技术契约）

1. **静态 glb**：轨道+支撑+站台+场景（合并后 draw call ≤ 40，体积 ≤ 6MB）；
2. **列车 glb**：独立导出，≤ 1.5MB，含 Seat/CamPov 锚点空物体；
3. **中心线 JSON**（核心交付）：沿弧长 0.5m 采样 ≈1650 点，每点
   `{s, pos[3], tan[3], up[3]（含banking）, zone, v_target}`，zone 枚举
   `station/lift/drop/loop/airtime/zerog/corkscrew/helix/brake`；
   > **As-Built 实发词表（12 种，游戏侧按此兼容）**：`station / dispatch / lift / drop / loop / climb /
   > zerog / corkscrew / sweep / uturn / return / brake`——`airtime`/`helix` 未使用（对应元素未建），
   > `dispatch/climb/sweep/uturn/return` 为表外细分；缝合样本 s=L 与 s=0 同点（v 1.5→2.0 由游戏侧站内逻辑接管）。
   - three.js 侧按 s 弧长查表插值驱动列车位姿，物理用能量守恒+分段阻尼，
     链条段锁 3.2m/s，刹车段 -4m/s²；
4. **乘坐流程**：站台登车→落座锁定→压杆→发车；相机 POV（切线看向）/第三人称追逐双模式，
   可随时切回步行走；出站回平台。

## 9. 工程规范（本项目踩坑记忆，写脚本必须遵守）

- 网格一律 `bpy.data` 直建（park_env helper），**禁用 primitive ops 逐对象建模**（9.6k 对象 50min 事故）；
- Blender 5.3：清默认场景再建、EXACT 布尔三铁律、枚举写全、顶点色勿留全白默认；
- 多材质 onBeforeCompile 注入必须配 `customProgramCacheKey`（松针磷光串用事故）；
- 导出后跑 `audit_float_geometry` 查悬浮；`far` 平面须 > 130m 包络+相机偏移（扩天穹风险）；
- 渲染验证固定 5 机位：全景正/侧/POV 头排/回环特写/站台，EEVEE 64spp 1600×900。
