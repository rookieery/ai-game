# 显灵木马 The Séance Carousel

幽夜游乐场 · 旋转木马设施资产（继摩天轮后第二个可乘坐设施）。

## 重建

```bash
/e/blender/blender.exe --background --python model/carousel/carousel.py
npm run assets:sync
```

产出：`carousel.blend` / `preview/*.png`（5 张预览）/ `carousel.glb`。
`P.render_video=True` 可渲旋转视频；预览灯 `CR_PvLight*` 与预览地面盘导出前自动移除。
改了场地件（台阶 / 围栏 / 招牌柱 / 平台 / 中柱）的几何后，同步 `scripts/patch_carousel_colliders.mjs` 里的静态碰撞。

## 设计参数（用户 2026-11-17 三问确认）

- 大型场地：平台 R8.0 / 骑乘环 R6.2（10 位弧间距 ~3.9m）/ 平台顶 0.62
- 三灵坐骑 ×8（i1/4/8 灵火幽灵马、i2/6/9 象牙鎏金马、i3/7 南瓜稻草马）+ 座车 ×2（i0 南瓜马车，入口位；i5 鎏金座车）
- 机台：锥顶帐篷 + 波浪裙边灯串 + 新月星芒顶饰 + 铜杆 + 甲板法阵
- 场地：铺装星徽（入口方位）、断弧地灯环、三级台阶、排队围栏、新月招牌
- 建模在原点，入口方位 azimuth 202°（= 世界 (45,18) 指向园区中心）

## 运行时节点契约

- `CR_Spin`：机台旋转总根（世界包围盒最薄轴 = 旋转轴）。屋面、天花内饰、吊灯、顶饰、甲板、法阵、灵光池、铜杆都在它下面。
- `CR_Ride_0..9`：每骑乘位起伏根（挂 `CR_Spin` 下，本地 +X = 行进切向；马 bob，座车静止）。
- 材质 `CR_*` 自发光件随「装饰灯亮度」联动；`CR_GhostBody` / `CR_Wisp` 带 alpha BLEND。
- 静态场地（铺装 / 围栏 / 台阶 / 招牌 / 地灯）不在旋转根下。

## 游戏接入（2026-11-17；2026-11-25 更新）

- `main.js` 把 glb 摆到 (45, 0, -18)，`__game.carousel` 钩子。
- `src/rides/carousel.js`：`CR_Spin` 程序化旋转（默认 18 秒/圈）+ 马位 sin 起伏（±0.22m，周期 3s）。
- 顶棚点光 ×3 挂在 `CR_Spin` 上，位置 = 吊灯灯球心，随屋面转；亮度归设置面板「显灵木马 · 顶棚灯光亮度」
  （`config.js` 的 `carouselCanopyLight`，基准强度 60）。不再挂摩天轮的「舱内灯光」。
- 骑乘眼高：灵兽 2.24（鞍面 1.50）、座车 2.22（座椅面 1.49）。盘面按 E 上就近灵兽 / 座车，E 下马回平台 r7.6。
- 提示与铭牌：`carousel.nameOf(骑乘位)` / `carousel.nearest()`；提示 = `骑上 + 坐骑名`，铭牌名 = 坐骑名。
- 同款灵兽合批：`carousel.instancedCount`（22 个 InstancedMesh / 58 个实例）；`carousel.setInstanced(false)` 运行时切回原网格
  （对照取证用），地址带 `?noinst` 时不合批。调试钩子 `__game.carousel`。
- **动态碰撞**（`carousel.js`，每帧读骑乘位世界位置）：马 = 沿切向 3 个圆（−0.85 r0.45 / 0 r0.55 / +1.05 r0.40，无限高）；
  座车 = 前后 2 个圆 r0.70、顶面高 1.40；铜杆 r0.10。
- **静态碰撞**（`scripts/patch_carousel_colliders.mjs`，可重复执行，圆带 `src:"carousel"`，共 111 个；另写入打卡点）：

## 评审清单（A–L）已全部做完；没归进清单的零碎项

- 幽灵马的火不闪：腿焰、鬃、尾是静态几何，运行时没有闪烁。
- 幽灵马腿焰穿甲板：按脚本参数推算，约 46% 的时间焰尖低于台面（最多穿出甲板底 1.5cm，被裙板挡住）。
- 骑坐相机在铜杆轴线上：仰俯超过 72° 会看到杆身（把相机后移 0.12m 到鞍座中心即可避开）。
- 地灯环是实心白漆圆管：辉光关掉时像一条白漆线。
- 过山车贴着木马（结构离檐口约 4.8m，轨面高 3.5–3.7m）：属于过山车资产的调光或定线。
