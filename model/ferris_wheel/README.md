# 幽眠摩天轮 v3（万圣节惊魂夜）

程序化生成的游戏引擎资产：轮体旋转 + 吊舱始终保持垂直（真实摩天轮特性）。
造型语言与缠魂塔、墓园一致：黑铁 + 暗夜紫 + 鎏金新月，万圣节夜。

## v3 舱体重做（2026-11-27，第 1 批）

2026-11-27 的建模评审（18/40）结论：舱不是细节不够，而是下半舱被封死、体量不是按人做的。
第 1 批把舱整体重做成「景版」——舱退到视野边缘，把画面让给园子；主题靠材质表达。

| 项 | v2 | v3 |
|---|---|---|
| 轮心高 / 轮顶 | 20.1 m / 36.1 m | **20.41 m / 36.41 m**（仍低于缠魂塔 40 m） |
| 舱外廓（沿轮缘 × 进深） | 1.86 × 1.32 m，读作售货亭 | **2.20 × 1.80 m**，舱体高 2.25 m + 吊架 0.45 m |
| 下半舱 | 实心漆面盒 + 整块金属窗台板，地板和坐面在游戏里从未可见 | **壳**：四周壁板 + 地板；窗台 / 窗顶是周边窄框 |
| 地板 / 净高 | 1.58 × 1.06 m / 1.62 m | **2.10 × 1.70 m / 2.00 m** |
| 眼高（园区 / 舱内站 / 坐） | 1.65 / 1.40 / 1.18（上舱缩 25 cm） | **1.65 / 1.65 / 1.20** |
| 舱内可走范围 | 1.24 × 0.32 m，正中一根中柱 | **1.76 × 0.95 m，没有中柱** |
| 窗台离地板 | 0.54 m（坐姿看不见脚下） | **0.40 m** |
| 玻璃 | 实心闭合盒，20% 深蓝，双面 | **4 片单层，6% 近无色，单面** |
| 门 | 两根门梃 + 门头（长椅背后也有一套） | **登舱侧整扇玻璃门 + 把手**；门框材质 `FW_DoorSignal` |
| 长椅 | 座板封在船体里，只有一块靠背 | **落地长椅** 1.92 × 0.44 m，绒面坐垫高 0.54，靠背顶 0.90（低于坐姿眼位），三个坐点 |
| 天花与光 | 整块发光板；点光在脚边 0.29 m | **深色天花 + 顶灯 + 窗顶光槽 + 发光盘**；点光在天花下 0.50 m |
| 涂装 | 橙 / 紫 / 绿 / 红四色轮换 | **统一**：黑铁框 + 暗夜紫漆 + 鎏金新月徽与顶饰 |

| 整机 draw call | 215（舱 192 + 轮体 9 + 站台 14） | **50**（舱 27 + 轮体 9 + 站台 14） |
| glb | 3.53 MB，17 条从不播放的动画，全带无用 UV | **0.92 MB**，无动画，无 UV |

**舱本地系**（Blender；枢轴在原点）：x 沿轮缘，+y = 长椅侧（北，app −z），−y = 登舱门侧（南，app +z），z 向上。
地板顶 −2.70 / 窗台 −2.30 / 窗顶 −0.72 / 天花底 −0.70。停靠时枢轴在 4.41，舱地板离站台 0.16 m（裙底离站台 0.06 m）。

**运行时（`src/rides/ferris.js`）**

- 舱体合批：glb 里 16 个舱节点（`FW_C<i>_<材质>`）引用同一套网格，载入后每种材质一个 `InstancedMesh`；
  原网格留在各舱根下、置为不可见，`ferris.setInstanced(false)` 可切回做对照。
- 登舱门框：`FW_DoorSignal` 每个舱一份材质。站台联锁吸附到位（轮停稳）时，最低的那一舱门框亮灵火青 `#8FE3D9`，其余全灭。
- 设置面板：`FW_CabinGlow / FW_CoveLight / FW_CabinLamp / FW_RoofLamp` 随「舱内灯光亮度」，
  其余发光材质（轮缘 / 彩点 / 轮毂 / 招牌 / 灯环 / `FW_Lacquer` / `FW_Gold`）随「装饰灯亮度」。
- 所乘舱的点光挂在舱中央、天花下 0.50 m（基准 22 cd × 舱内灯系数）。

**回归**：`node scripts/verify_cabin_ceiling.mjs <目录>`（净空断言 −0.80 / 坐姿 −1.50）、
`node scripts/screenshot.mjs <目录> cabin`（长椅 / 外墙 / 横穿舱心 / 坐站）、`verify_settings`、`verify_jump`、`verify_fw_salute`。


## v3 站台成为必经之路（2026-11-27，第 2 批）

第 1 批之后站台还在主流程之外：地面和站台各有一个登舱点，整座站台可以绕过，人能直接走进停靠舱，站台没有真实光源。
第 2 批把登舱做成一条动线：**入口门楼 → 台阶 → 排队通道 → 登舱闸 → 停靠舱**。

| 部位 | 之前 | v3 第 2 批 |
|---|---|---|
| 入口 | 台阶直接接在主路上 | **入口门楼**（台阶脚，app z 17.4）：两根黑铁柱 + 鎏金柱箍和柱尖 + 横梁 + 鎏金新月，柱内侧挂灯笼 |
| 台阶 | 光台阶，两侧 x ±2.7 一小段围栏 | **通长铁艺扶手**（x ±2.3，app z 8.6–16.5），台阶脚和台阶口的柱顶挂灯笼；旧围栏删除。最上一级加深到 1.2 m、塞进圆台下面 |
| 站台面 | 一整块空台面 | **排队通道**：铁艺围栏 x ±0.8、app z 2.0–8.85，柱顶灯笼；东侧 z 4.0–6.0 留开口，台阶两侧上来的人从这里进通道 |
| 登舱口 | 没有，人直接走进停靠舱 | **登舱闸**：对开双扇铁艺门，扇面各一枚鎏金新月；只在轮停稳、舱吸附到位时开 |
| 渡板 | 没有 | 停靠舱门前的**小踏板**（顶 1.69）+ 地面一圈**鎏金登舱标线** |
| 登舱点 | 地面 (0,16.4) 和站台 (0,1.6) 各一个，半径 2.6 | **只在闸口**（app (0,1.3) r 1.0 且 z < 2.3，即开着的闸门口或过闸之后；且轮已停靠）；地面只出指路提示「乘坐摩天轮 · 请上站台」 |
| 下乘 | 永远送回台阶下的地面点 | **落回站台东侧** (2.4, 0.6)，面向南侧台阶，提示「已回到站台 · 南侧台阶下台」 |
| 停靠舱 | 能走进去 | **实体**：盒墙 2.44 × 2.04（含檐板），南 / 东 / 北三个方向真键都走不进 |
| 站台照明 | 没有真实光源 | **吊灯 ×2**（自发光灯芯 + 点光 38 cd）+ 门楼 / 扶手 / 围栏灯笼；新增滑杆「站台灯光亮度」 |

**动线坐标**（app：x 东、z 南，停靠舱门朝南）都写在 `src/player/controller.js` 的 `STATION` 常量里；模型脚本「v3 第 2 批」段、`interact.js`、`main.js`、`ferris.js` 都从那里取，改模型时一起改。

**运行时**

- 闸门：`FW_BoardGate_L / _R` 是两个空节点（铰链在 app (∓0.70, 1.55, 1.90)），子网格是门扇。`ferris.js` 每帧把开度（`gateOpen01()`，0 关到 1 开，一程 1.1 s）转成绕世界竖轴的 ±90°，开位贴回两侧围栏往南，不侵入停靠舱；`main.js` 按 `ferris.gatePassable` 开关闸线碰撞（tag `fwGate`）：开始开就放行，关严才重新挡。
- 防夹：人还在闸线带里（`|z − 1.9| < 0.75`、脚高 < 3.2）时不落闸。跳跃会让站台联锁松开一瞬（脚高越过 2.2），闸门不能趁人腾空时落下来。
- 状态灯：闸柱灯 `FW_GateSignal` 和停靠舱门框 `FW_DoorSignal` 是同一个状态，停靠时亮灵火青，其余全灭。
- 灯：两盏吊灯点光常驻、只调强度；`FW_StationLamp`（灯笼 + 吊灯灯芯）随「站台灯光亮度」（`ferrisStationLight`，默认 100% = 每盏 38 cd）。
- 碰撞（都在 `controller.js`）：停靠舱盒墙、通道围栏薄盒（不用圆链，异径圆链会被斜向走线挤穿）、闸线、台阶扶手薄盒，门楼柱 / 闸柱 / 开口柱用圆。
  **直接 `push` 进 `stallRects` 的墙必须带 `solid: true`**——漏了会被当成台阶顶面，整面墙不生效，截图看不出来，只有真键走线能发现。

**实测**

- 站台视角（东南角看向停靠舱）：默认设置均亮 52.5 → 78.3，近黑像素 21.6% → 6.0%；用户设置（辉光 20 / 装饰灯 30 / 园区照明 25）下均亮 14.8 → 31.3，近黑 78.7% → 45.4%。
- 整机网格 50 → 57（静组多出鎏金件、站台灯具、闸柱灯，闸门 4 个子网格），用户机位全园 draw call 392 → 399，帧耗时不变（6.9 ms）。glb 0.93 MB → 1.06 MB。
- 闸门开合方向、停靠舱三面挡人、通道围栏、台阶扶手、两条上台阶路线（中间 / 东侧经开口）、下乘落点、闸线带里跳跃不落闸，都是真键走线断言。

**回归**：起 dev server 后 `GAME_URL=http://127.0.0.1:8767 node scripts/verify_ferris_station.mjs`（53 项，`ONLY=C,F` 可单块重跑）。
原先靠地面登舱点登舱的脚本（`verify_cabin_ceiling`、`screenshot.mjs`、`verify_settings`、`verify_v3`、`verify_fw_salute`）都改成传送到闸内、等 `ferris.isDocked()` 再按 E；`verify_jump` 的下乘断言改成落回站台东侧。

## v3 站台与轮体造型（2026-11-28，第 3 批）

评审清单里剩下的造型项。动手前先核了结构，三条硬约束决定了设计：

- **雨棚沿轮面方向最多伸到 x ≈ 5.9 m。** 舱的吊架顶走的是 R 16.1 的圆，x = 5.9 处离地 5.64 m；檐口灯带底 5.88 m，余量 0.24 m，再往外吊架会扫穿屋檐。
- **两榀支腿之间不能有任何杆件。** 轮子扫过的范围是 |y| ≤ 2.51（轮缘灯珠到 2.45、轮毂发光环到 2.51）；原模型两榀之间的 3 道 y 向横撑和交叉撑都穿过这个范围，辐条转过来会从杆件里穿过去。
- **轴承座必须在轮毂盘外侧**（|y| ≥ 2.7）。原座在 |y| 1.45–2.35，和转动的轮毂盘重叠。

| 部位 | 之前 | v3 第 3 批 |
|---|---|---|
| 雨棚平面 | 方锥（角在 ±6.22）套一个圆环灯带 R 6.55：灯带沿轴向外伸 0.33 m、在角上缩进 1.59 m | **八边形椭圆**，半轴 5.9 × 8.6；**灯带贴在封檐板下沿**，与椽头对齐 |
| 雨棚棚底 | 一整块平板，仰视没有椽梁 | **薄壳**：仰视看得见 8 根椽子、两道檩、顶心圈和**鎏金新月吊坠** |
| 雨棚吊灯 | 8 盏，吊杆顶端都在屋面投影外 | 删除。换成**檐口灯笼 ×6**（挂在檐角和斜向檐口中点）；两盏站台大吊灯改挂中央椽子 |
| 雨棚柱 | 4 根，角在 (±6.22, ±6.22) | 4 根，挪到斜向 4 个檐角下 (±4.17, ±6.08)，带柱座、鎏金箍、柱帽 |
| 支腿 | 4 根 r 0.30 光圆管；两榀之间 3 道横撑 + 交叉撑（穿过轮辐平面） | **两榀平面格构 A 字架**（各在 \|y\| = 3.0 的平面里：每根柱 4 根弦杆 + 8 层缀条 + 斜缀条，截面 0.70 → 0.44；平面内 4 道横撑 + 之字斜撑）。两榀之间不再有杆件 |
| 腿顶 | 接在转动的轮毂盘上（r 1.1 处） | 接**轴承座**：座筒 r 0.62 在 \|y\| 2.70–3.30，轴接长到 ±3.40 从座里穿过，外端加端盖 |
| 支腿脚 | 底板埋在台体里 | **站台面上的方座 + 钢底板 + 4 颗地脚螺栓**，看得见 |
| 轮毂 | 白色发光环 | 发光环保留，盘面加**鎏金新月徽**（外径 1.12，随轮转；盘面中心被静止的轴承座挡着，徽小了只剩边角） |
| 柱灯顶 | 四色小球 | **小南瓜灯** ×13（带瓣纹，脸朝灯外；台阶口那两盏朝南） |
| 轮缘灯珠 | 暖白 / 橙 / 紫 / 绿四色 | **暖白 + 暗夜紫**两色 |
| 登舱时舱内灯 | 登舱即全亮 | **1.2 s 由暗转亮**（所乘舱的点光从 0 推到设定值；下乘后收起） |

**运行时**

- 登舱点光：`ferris.board()` 把点光强度置 0，`update` 每帧把开度推到 1（`CABIN_LIGHT_T` = 1.2 s，缓入）；`ferris.rideLight` 是取证 / 回归用的引用。舱内的自发光件（发光盘 / 光槽 / 顶灯）16 个舱共用材质，不跟着做逐舱渐亮。
- 碰撞（`controller.js`）：雨棚柱圆 (±4.172, ±6.081) r 0.17；支腿脚盒墙 (±6.2, ±3.0) 半宽 0.64。
- 材质分组：`FW_Pumpkin / FW_PumpkinFace` 随「装饰灯亮度」；檐口灯笼与站台大吊灯的灯芯都是 `FW_StationLamp`，随「站台灯光亮度」。`FW_RoofLamp` 现在只用在舱檐口灯线上。

**实测**：整机网格 57 → 53（静组 17 → 14、轮体 9 → 8、闸门 4、舱 27），用户机位全园 draw call 399 → 395，帧耗时不变。glb 1.06 → 1.35 MB，三角面 9.8 → 11.1 万。
整轮远景的亮度基本不变；雨棚顶面那一张变暗（均亮 64 → 43），因为原来横在屋顶上的圆环灯带和悬空吊灯没有了。

**回归**：`verify_ferris_station.mjs` 加了两块（I 登舱灯由暗转亮、J 雨棚柱 / 支腿脚），共 61 项。

**三批之后还没做的**：登舱仍是淡入淡出，舱门不做开合动画；没有检票机制（售票亭是装饰）；`colliders.json` 的 `boarding` 字段闲置。

## 引擎端约定（应用端依赖，勿改节点名）

- `FW_Wheel`：轮体总根（程序化绕世界轮轴旋转，轴由包围盒最薄维度几何检测）
- `FW_CabinRoot_0..15`：每舱摆正参照根（应用端每帧锁定世界姿态保持水平）
- 舱内第一人称走动（glTF 本地坐标，应用端 `controller.js` 的 `CABIN` 常量同步约束）：
  地板顶 −2.70 / 净高 2.00（天花底 −0.70）；站姿眼高 1.65、坐姿 1.20；地板 2.10 × 1.70；
  长椅占 z ∈ [−0.86, −0.42]（app 坐标，坐垫顶 0.54），可走范围 x ±0.88、z −0.27…0.68；登舱落位 (0, 0.35) 在门侧
- `FW_BoardGate_L / _R`：登舱闸两扇门的铰链节点（子网格是门扇；运行时绕世界竖轴各转 90° 开合，见上文「运行时」）
- 登舱站台顶 1.55 m，落舱地板 1.71 m（跨步 0.16 m）；应用端站台碰撞圆 r 9.0（`controller.js`），联锁半径 9.8（`main.js`）
