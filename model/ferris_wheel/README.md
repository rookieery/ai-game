# 幽眠摩天轮 v2（万圣节惊魂夜）

程序化生成的游戏引擎资产：轮体旋转 + 吊舱始终保持垂直（真实摩天轮特性）。

## v2 规格（对比 v1）

| 项 | v1 | v2 |
|---|---|---|
| 半径 / 舱数 / 轴高 | 12m / 12 / 15.5m | **16m / 16 / 20.1m** |
| 轮体 | 单轮缘 + 12 辐条 | 双弦杆轮缘桁架 + 之字腹杆 + 内环 + 24 辐条 + 细张拉杆 |
| 舱体 | 方盒、无内饰 | 弧顶灯笼 + 1.30m 密分格玻璃带 + **内饰**（地板/端墙长椅/中柱/暖光天花墙裙, v2.2 舱顶抬高压）+ 四向南瓜徽牌 + 门框 |
| 色板 | 粉青霓虹 | 南瓜橙/暗夜紫/磷光绿/暗红 + 暖白灯 |
| 站台 | 光板圆盘 | 1.55m 高站台（8 级台阶/六柱尖顶雨棚/排队围栏/售票亭/矮柱灯） |
| 面数 | 4.3 万 | 8.5 万 |
| 灯光 | 无 | 每舱 12W 暖光点光源（glTF KHR lights，随舱转） |
| draw call | ~900 对象 | **按材质分组合并**：静组 15 + 轮体 9 + 每舱 11×16 |

## v2.3 场景贴合修复

- **悬浮修复**：售票亭/排队围栏/12 矮柱灯原先按站台面标高（+1.55）定位，但平面位置都在站台半径 r9 之外 → 整体悬空 1.55m。现全部落地（z=0 起步）；排队围栏外移 x=±1.5 → ±2.7（原位落地会埋进台阶体），台阶口两侧各补一盏矮柱灯（南向原位让位台阶）。
- **台阶悬浮错觉**：FW_GroundRing1 (r12.5) 南向断弧 ±13°，发光线不再从台阶中段下方穿过（台阶本身是落地的）。
- **合并失效修复**：`join_group` 的 groups 字典从未填充，合并静默跳过，glb 实际 1266 个独立 mesh；现真正按材质合并（join 前逐对象应用倒角修改器，避免活动对象修改器参数套用整组）。
- **FW_Ground 只进 blend/预览**：legacy r70 地面盘顶面 y=0 会盖住公园地坪（顶 y=-0.05），glb 导出前移除；应用端 main.js 的运行时删除逻辑已同步移除。
- 应用端配套：`controller.js` 为落地后的售票亭/围栏/矮柱灯补碰撞圆。

## 引擎端约定（应用端依赖，勿改节点名）

- `FW_Wheel`：轮体总根（程序化绕世界轮轴旋转，轴由包围盒最薄维度几何检测）
- `FW_CabinRoot_0..15`：每舱摆正参照根（应用端每帧锁定世界姿态保持水平）
- 舱内第一人称走动（v2.2，glTF 本地坐标，应用端 `controller.js` 同步约束）：
  地板顶 -2.34 / 净高 1.62（发光天花底 -0.72，v2.2 抬高舱顶修复站姿抬头穿梁）；站姿眼高 1.40、坐姿 1.18；地板 1.58×1.06；
  端墙长椅占 z ∈ [-0.53, -0.11]，中柱 r 0.045 在原点（应用端按此做解析碰撞）
- 登舱站台顶 1.55m，落舱地板 1.76m（跨步 0.21m），应用端站台碰撞圆 r9.8
