# 园区环境（幽夜游乐场）

万圣节夜场园区：南入口大门 → 石板主路 → 中央广场（摩天轮坐落原点，轮盘资产独立）。

## 内容清单

| 分区 | 内容 |
|---|---|
| 地面 | 地坪 r88 + 广场盘 + 橙/紫双发光环(南向台阶走廊断弧 ±13°, v2.3) + 主路 4 段 + 环形支路 + 草地带 |
| 入口 | 石造大门（双柱锥顶/门灯/紫光招牌）+ r84 铁艺围栏（220 尖桩 + 双横杆） |
| 灯光 | 维多利亚路灯 ×12 + 悬链灯串 ~15 条（四色灯珠）+ 缠灯松树 ×5 |
| 植被 | 递归分枝枯树 ×15（seed=11 可复现） |
| 点缀 | 南瓜灯 ×20（雕刻脸自发光）+ 墓园角落（9 墓碑/2 十字架/紫火灯笼）+ 市集亭 ×3（条纹雨棚）+ 长椅/干草/木桶 |
| 远景占位 | 旋转木马 + 过山车剪影（v2 换真设施）+ 山脊环 + 70 点城市灯火 |

## 输出三件套

| 文件 | 用途 |
|---|---|
| `park_env.glb` | 全部按材质合并成 23 个网格（≈23 draw calls） |
| `colliders.json` | **app 坐标系**（x, z）：86 碰撞圆 + 边界 r82.5 + 出生点 + 登舱点 + 7 兴趣点（含 5 打卡簇）。与模型同源生成，改布局重跑脚本即可 |
| `preview/*.png` | 俯视全景 / 主路街景 / 墓园角落 |

## 生成

```
E:\blender\blender.exe --background --python park_env.py
```

## 坐标换算（重要）

Blender (x, y, z) → glTF (x, z, -y)。colliders.json 已自动换算到 app 空间；在 Blender 里新加道具时记得同步加 `collider(x, y, r)`。
