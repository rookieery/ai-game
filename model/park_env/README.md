## 输出三件套

| 文件 | 用途 |
|---|---|
| `park_env.glb` | 全部按材质合并成 ~30 个网格（≈30 draw calls） |
| `colliders.json` | **app 坐标系**（x, z）：边界 r144.5 + 出生点 (0,144) + 登舱点 + 释放器锚点 + 10 打卡 POI + 碰撞圆/矩形（含围挡分段矩形）。与模型同源生成；**旋转木马碰撞由 scripts/patch_carousel_colliders.mjs 重跑后回补** |
| `preview/*.png` | 俯视全景 / 主路街景 / 墓园角落 |

## 生成

```
E:\blender\blender.exe --background --python park_env.py
node scripts/patch_carousel_colliders.mjs   # 回补木马手工碰撞（勿跳过）
npm run assets:sync
```

## 坐标换算（重要）

Blender (x, y, z) → glTF (x, z, -y)。colliders.json 已自动换算到 app 空间；在 Blender 里新加道具时记得同步加 `collider(x, y, r)`。
